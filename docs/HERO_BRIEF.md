# Hero comparison brief

One armored tortoise courier robot combines organic head and feet, beveled hard-surface armor, exposed gears/joints, raised readable **NANODE 01**, and a folded stitched fabric saddle pouch. All details should form one coherent courier silhouette.

| Dimension / convention | Fixed requirement |
|---|---|
| X width | 0.60 m |
| Y length | 0.90 m |
| Z height | 0.65 m |
| Forward | −Y |
| Ground | Z=0 m |
| Center | X=0, Y=0 m |
| Views planned | Front, rear, side, top, identical cameras |
| Iterations requested | Five distinct build/export versions per arm |
| Limits per arm | 30 tool actions; 8,192 output-token cap per action; 65,536 total context |

The corrected comparison finished with **zero exported meshes in both arms**. First and fifth versions, fixed-camera renders, physical validation and semantic scores therefore do not exist. The four missing panels are the actual outcome. Distinct content hashes would demonstrate distinct versions, not useful refinement; none were recorded.

This asset is a future end-to-end target, not an achieved deliverable or production-quality mesh claim.
